Breezefile · Task Experience — Going Broad

Phase 3 inspirations. Nine deliberately diverse, low-fidelity prototypes for making the agentic task experience simple and delightful — calm by default, powerful on demand. Each explores a distinct paradigm against the three jobs: monitor running agents live · triage the overview · create agentic tasks from intent. Not pick-a-winner — these are for comparing, combining, and converging in Phase 4.

Same scenario runs through all nine, so you can compare paradigms on identical data: 3 agents need you · "Nightly deploy" has been blocked 41 min on a failing auth.spec.ts · "Migrate beads" is asking a y/n · Priya's "Refactor TaskRow" is on step 3/5 · the team shares the encrypted TypeBuild queue.

The nine explorations

01
Mission Control
Live dashboard cockpit

Dark command center: every running agent is a live tile with state pill, ticking last-action, step trace and pulse. Bulk-select → stop/nudge across agents. To-dos in a quiet rail.

Live awareness★Direct controlCalm clarity
02
Command Bar
Conversational single input

One ⌘K input drives everything. Plain intent ("ship the auth PR after tests pass") renders a structured task proposal inline — inferred agent/folder/trigger, one field it can't infer, a step plan, and a runtime+token dry-run estimate. Leads with recipes.

Intent→action★Power w/o machineryCalm clarity
03
Attention Lanes
Calm three-lane board

Lanes by who-must-act: Needs you · Agents working · Done/FYI — not a status board. Cards minimal until focused; j/k/h/l nav; mine-vs-theirs avatars; PHI titles reveal on focus. A clean empty-lane state surfaces the unclaimed P0.

Calm clarity★Team coordConfidentiality
04
Agent Inbox
Triage stream like email

One urgency-sorted inbox: agent y/n prompts, blocked runs, finished runs awaiting accept/redo, due to-dos. Inline reply box steers an agent in place. e/r/enter. "What changed" summaries with Accept/Redo. Inbox-zero celebrated.

Triage★Direct controlTrust/audit
05
Living Timeline
Activity stream / CI feed

Time-ordered feed of agent actions with per-step "why" lines (the audit ledger). Running agents pinned on top with live progress; a JS tick appends real events. Filter by agent or "needs me"; click an event to drop into the run.

Live awareness★Trust/audit★Direct control
06
Ambient Canvas
Spatial node graph / map

Calm 2D canvas showing a workflow's containment (parent→child steps) and ordering (blocked-by edge glows red Test→Promote) — power without Jira machinery. Zoom: far = constellation, near = node detail with steer/answer/stop.

Power w/o machinery★Live awarenessCalm clarity
07
Single Focus
One thing at a time

Radical calm: the screen shows the single most important thing to handle — the blocked deploy, full-bleed, with its trace, the failing test, and act/steer/skip/stop. Slim rail: "1 of 3 need you." enter/n/s. All-clear terminal state.

Calm clarity★Direct control
08
Split Monitor
Grounded list + live detail

Fast attention-sorted list on the left (secondary controls revealed on focus only); live session detail on the right with streaming actions, per-step "why", inline steer, Stop/Pause/ Retry, and "what changed" + Accept/Redo. Proves: keep the power, defer the clutter.

Calm clarityLive awarenessDirect controlTrust/audit
09
Fleet Roster
Agents-as-a-team mental model

Reframes around the agents, not the task list. Humans (you/Priya/Sam) and agents share one roster with health + track record. Hero flags idle vs overloaded vs stuck. Creating work = "give this to an agent" picked from the roster.

Team coord★Intent→actionPower w/o machinery

Tensions each navigates

Live awareness vs. clutter — Mission Control (01), Timeline (05), Split (08) lean information-dense; Single Focus (07) and Attention Lanes (03) suppress almost everything. The convergence question: how much live signal before calm breaks?
Transparency vs. trust burden — surfacing every per-step "why" (05, 08) makes agents auditable but asks the operator to read more; Inbox (04) and Single Focus (07) summarize instead.
Intent freedom vs. structure — Command Bar (02) and Fleet (09) let you say it in a sentence; the proposal/roster supplies structure. Risk: over-inferring and getting it wrong — both show the inferred plan before committing.
Tasks-centric vs. agents-centric — eight variations organize around work; Fleet (09) organizes around workers (human + agent). Worth testing which mental model the team adopts.
